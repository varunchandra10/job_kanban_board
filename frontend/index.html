Core Capabilities

Features Built In This Project

Everything you need to run an organized, structured job search without spreadsheet clutter.

4-STAGE PIPELINE

Visual Kanban Board

Organize applications across 4 visual stages: Applied, Interviewing, Offer, and Rejected. Drag and drop cards, filter by track (Industry, Government, Research), and search instantly with /.

PRIVATE CLOUD

Personal Google Drive Storage

Uploaded resumes and cover letters stream directly into your personal Google Drive folder via official Google Drive API integration. Your files are never stored on shared admin servers.

HABIT TRACKING

Daily Learnings Diary & Streak

Log technical takeaways, interview questions, and prep notes daily. Maintain a glowing activity streak counter to stay disciplined and prepared for every round.

VISUAL MATRIX

Career Hub & Heatmap

View your monthly activity matrix heatmap showing applications submitted and daily learnings logged, along with tailored resume version tracking.

STRICT ISOLATION

Google OAuth & Privacy

Sign in securely using Google OAuth or custom email. Multi-tenant database queries strictly isolate data by user ID so you never see another user's records.

OFFLINE FREEDOM

1-Click CSV & SQLite Backup

Export all application records to clean CSV or download the complete SQLite database as a ZIP file anytime for offline archiving and total data ownership.
